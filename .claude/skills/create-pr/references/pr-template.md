# PR Templates

두 가지 템플릿이 있다. 프로젝트 성격에 따라 하나를 선택한다.

## 판단 기준

**영문 템플릿 (오픈소스)** — 아래 중 하나라도 해당되면:
- `CONTRIBUTING.md` 또는 `CONTRIBUTORS.md`가 존재
- `LICENSE` 또는 `LICENSE.md` 파일이 존재
- 리모트 URL이 조직 계정 소속 (개인 계정이 아닌 경우)
- 사용자가 "오픈소스", "open source", "외부 기여" 등을 언급

**한국어 템플릿 (개인 프로젝트)** — 그 외 모든 경우

---

## Template A — English (Open-source)

```
## Summary

<!-- One paragraph: what this PR does and why. -->

## Changes

<!-- Bullet list of specific changes. -->
-

## Testing

<!-- How was this tested? What scenarios were covered? -->
-

## Related Issues

<!-- Fixes #<issue>, Closes #<issue>, or N/A -->

## Checklist

- [ ] Tests added or updated
- [ ] Documentation updated (if applicable)
- [ ] No breaking changes (or clearly noted above)
```

---

## Template B — Korean (개인 프로젝트)

```
## 요약

<!-- 한 문단: 이 PR이 무엇을 하는지, 왜 필요한지. -->

## 주요 변경 내용

<!-- 구체적 변경사항을 항목으로 나열. -->
-

## 테스트 방법

<!-- 어떻게 테스트했는지, 어떤 시나리오를 검증했는지. -->
-

## 관련 이슈

<!-- 관련된 이슈 번호 또는 없음 -->

## 체크리스트

- [ ] 테스트 추가 또는 수정
- [ ] 문서 업데이트 (해당 시)
- [ ] 하위 호환성 유지 (또는 위에 브레이킹 체인지 명시)
```
